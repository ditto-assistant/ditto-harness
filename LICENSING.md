## Do I need a commercial license?

Use this decision guide:

| Your situation | License needed |
|---|---|
| Personal project, research, or internal tooling — you publish all source | AGPL (free) |
| Open-source project that is itself AGPL-compatible | AGPL (free) |
| You run a network service and will publish all modified source to users | AGPL (free) |
| You distribute a product and will include full AGPL source | AGPL (free) |
| You run a SaaS/hosted service and do **not** want to publish modifications | **Commercial** |
